Privacy Policy for backup.
Last updated: September 17, 2026
This policy explains what data backup. collects and how it is used. The app is a Discord application that adds users to a server only after they authorize it with Discord OAuth2 (identify and guilds.join).

1. Who we are
Operator: nora.
Contact: sharkthegreatest100@gmail.com

2. Data we collect  
- Discord user ID and username (from the identify scope)  
- OAuth access/refresh token metadata needed to call guilds.join  
- Guild IDs the user or a server admin associated with restore  
- Timestamps of authorization, restore attempts, and revocation
We do not collect email, password, payment info, message content, or presence.

3. How we use it  
- Know who authorized the app  
- Add only those users to a destination server when an admin runs restore  
- Skip users who already joined or revoked access  
- Respond to deletion requests
We do not sell data, use it for ads, or add people who never authorized the app.

4. Legal basis / consent
Data is processed because the user clicked Authorize on Discord’s OAuth screen. They can revoke the app anytime in Discord → Settings → Authorized Apps.

5. Sharing
We do not share personal data except:  
- with Discord, to perform the join API  
- if required by law

6. Retention
We keep authorization data until the user revokes access or asks us to delete it, or until it is no longer needed for the restore feature. Tokens that fail or are revoked are deleted.

7. Your rights
You can:  
- Revoke the app in Discord  
- Email sharkthegreatest100@gmail.com to request deletion of stored IDs and tokens
We will delete stored data associated with your user ID after we verify the request.

8. Security
Tokens are stored with restricted access. We do not publish member lists.

9. Children
The app is not directed at children under 13. Do not authorize it if you are under 13.

10. Changes
If this policy changes, we will update the date at the top of this page.

11. Discord
Use of Discord is also covered by Discord’s Privacy Policy and Terms of Service.
